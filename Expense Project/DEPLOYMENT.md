# 🚀 Deploy Kushala's Expense Tracker to GitHub

## 📋 Step-by-Step Deployment Guide

### Step 1: Create a GitHub Account
1. Go to [GitHub.com](https://github.com)
2. Click "Sign up" if you don't have an account
3. Choose a username (e.g., "kushala" or "kushala-dev")
4. Verify your email

### Step 2: Create a New Repository
1. Click the "+" icon in top right corner
2. Select "New repository"
3. **Repository name**: `expense-tracker`
4. **Description**: "A modern web-based expense tracker with Indian currency support"
5. Make it **Public** (so GitHub Pages works for free)
6. ✅ Check "Add a README file"
7. Click "Create repository"

### Step 3: Upload Your Files
Since Git isn't installed, we'll use GitHub's web interface:

1. **In your new repository**, click "uploading an existing file"
2. **Drag and drop ALL these files** from your project folder:
   ```
   📁 css/
     └── styles.css
   📁 js/
     └── app.js
   📁 .vscode/ (optional)
     ├── launch.json
     └── tasks.json
   📄 index.html
   📄 package.json
   📄 README.md
   📄 test.html
   📄 .gitignore
   ```

3. **Commit message**: "Initial commit - Kushala's Expense Tracker"
4. Click "Commit changes"

### Step 4: Enable GitHub Pages
1. In your repository, click **Settings** tab
2. Scroll down to **Pages** section (left sidebar)
3. Under **Source**, select "Deploy from a branch"
4. Choose **Branch**: `main` (or `master`)
5. Choose **Folder**: `/ (root)`
6. Click **Save**

### Step 5: Access Your Live Website
After a few minutes, your site will be live at:
```
https://[your-username].github.io/expense-tracker
```

For example: `https://kushala.github.io/expense-tracker`

## 🔄 Making Updates Later

### Option 1: GitHub Web Interface
1. Go to your repository
2. Click on the file you want to edit
3. Click the pencil icon (Edit)
4. Make changes
5. Commit changes

### Option 2: Install Git (Recommended for frequent updates)
1. Download Git from [git-scm.com](https://git-scm.com)
2. Clone your repository locally
3. Make changes and push updates

## 📱 Mobile App-like Experience
Your GitHub Pages site can be added to mobile home screens:
- **iPhone**: Safari → Share → "Add to Home Screen"
- **Android**: Chrome → Menu → "Add to Home Screen"

## 🚨 Important Notes
- **Data Storage**: Each user's data is stored locally in their browser
- **Privacy**: No data is sent to servers - completely client-side
- **Updates**: Changes to your repository automatically update the live site
- **Custom Domain**: You can later add a custom domain if desired
